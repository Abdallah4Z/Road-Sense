# Plan: Milestone 3 - Inference & Deployment

## Current State
- Baseline model trained (exp34332): mAP50-95 = 0.76786, mAP50 = 0.94159
- Best checkpoint: `models/checkpoints/best-3classes-exp34332.pt`
- Presentation website deployed to GitHub Pages

## Goal
Build inference and deployment path for the trained Road-Sense model.

## Deliverables

### 1. Inference Script (Priority: High)
Create `src/models/inference.py` with CLI interface for running predictions:
- Single image prediction
- Batch prediction on directory
- Video prediction
- Confidence threshold argument
- Output with bounding boxes drawn

### 2. Real-time Detection Module (Priority: High)
Create `src/models/realtime.py` for video stream processing:
- Webcam input support
- Video file processing
- Frame-by-frame detection with visualization
- FPS/detection overlay

### 3. Demo Web Interface (Priority: Medium)
Add inference demo to presentation website:
- Upload image for detection
- Display results with bounding boxes
- Show class labels and confidence scores

### 4. Export for Deployment (Priority: Medium)
Export model to deployment-friendly formats:
- ONNX export (for cross-platform inference)
- TensorFlow Lite (for mobile/edge)

## Implementation Steps

1. **Create inference.py**
   - Load trained model from checkpoint
   - Accept image/video input
   - Draw bounding boxes with labels
   - Save annotated output

2. **Create realtime.py**
   - Initialize video capture
   - Process frames in loop
   - Overlay detections on frames
   - Display real-time results

3. **Add demo to presentation website**
   - Create upload interface in presentation/
   - Implement client-side inference (or connect to backend)
   - Display annotated results

4. **Export model formats**
   - Run YOLO export commands for ONNX/TFLite
   - Document export usage
