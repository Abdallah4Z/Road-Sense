Features

What it does

Everything you need to run object detection in production, from a single API call.

⚡

44 FPS on GPU

ONNX FP16 inference with CUDA execution provider. Zero accuracy loss.

🎯

Three-class detection

Vehicle, Pedestrian, Cyclist. mAP@50 = 0.935 on KITTI.

🔗

Temporal tracking

IoU-based tracking with session IDs. Objects stay tracked across frames.

📊

Prometheus metrics

Latency percentiles, request rates, error tracking at /metrics.

🔒

No auth required

Open CORS, multipart upload, JSON response. No API keys to manage.

📦

19.7 MB TFLite INT8

Edge-ready. 49% smaller than PyTorch, zero accuracy loss.

API Reference

Endpoints

REST API with JSON responses. CORS open. No authentication.

MethodPathDescription
POST/detectRun inference on an uploaded image. Returns JSON with detections, annotated image, and latency.
POST/detect_batchBatch inference on multiple images. Returns array of results.
GET/healthLiveness check. Returns model status, memory, latency stats.
GET/docsInteractive Swagger UI with live API testing.
GET/metricsPrometheus-format metrics endpoint.
