Endpoints

API

RESTful API deployed on Azure Container Instances (Sweden Central). All endpoints return JSON.

GET

/health

System status, model info, RAM usage, latency percentiles, request counts, error rate.

Check now →
POST

/detect

Upload an image → returns JSON detections (class, confidence, bbox, track_id) + base64 annotated image.

POST

/detect_batch

Upload multiple images → returns array of detection results, one per image. Supports up to 10 images.

GET

/docs

Interactive Swagger UI — try all endpoints directly in the browser with live responses.

Open Swagger →
GET

/redoc

ReDoc alternative API documentation with schema details and code samples.

Open ReDoc →
GET

/metrics

Prometheus-formatted metrics for production monitoring. Compatible with Grafana dashboards.
