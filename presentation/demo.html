/03 api REST over JSON. CORS open. Multipart for /detect. No auth. 0.65 s p50 on CPU.
methodpathdescription
GET /health Liveness probe. Returns server status, loaded model path, and rolling 100-request performance stats.
POST /detect Single-image inference. Multipart: image (file), conf (0–1, default 0.25), session_id (string, enables temporal tracking).
POST /detect_batch Batch up to 10 images in a single request. Returns one entry per input.
GET /docs OpenAPI / Swagger UI. Try requests, see schemas, copy as curl.
GET /redoc ReDoc alternative documentation with code samples.
GET /metrics Prometheus-format metrics. Compatible with Grafana, Datadog, etc.
/04 system Live snapshot of the running container. Refreshes on focus.
