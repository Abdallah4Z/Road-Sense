Format comparison.

Single-image latency at 640×640, NVIDIA RTX 3050 (4 GB VRAM), no batching. YOLO11m HPO checkpoint, identical weights across all formats.

Format Size FPS p50 p95 p99 mAP@50 Notes
ONNX FP16recommended 38.3 MB 44.1 22.7 ms 28.4 ms 34.5 ms 0.935 Best speed/accuracy trade-off
PyTorch 38.8 MB 33.6 29.8 ms 35.2 ms 42.1 ms 0.935 Baseline; used by the API server

API

Endpoints.

REST over JSON. CORS is open. All requests are multipart for /detect and /detect_batch.

MethodPathDescription
GET /health Liveness probe. Returns server status, loaded model path, and rolling performance stats.
POST /detect Run detection on a single image. Multipart form: image (file), conf (float, 0–1), session_id (string, for tracking).
POST /detect_batch Run detection on a list of images in a single request. Returns one response per input image plus a total time.
GET /docs Interactive OpenAPI / Swagger UI generated by FastAPI.
GET /metrics Prometheus metrics. Includes default FastAPI instrumentation plus request and latency histograms.

Architecture

From commit to inference.

One pipeline, one container, one model. No background workers, no message brokers, no GPU in production.
